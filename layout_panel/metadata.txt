about=This plugin adds a new panel to manage print layouts directly from QGIS main window. It allows to quickly open, create, rename, delete and filter print layouts without having to open the layout manager. It supports layout templates and also makes it possible to batch export one or multiple layouts to PDF, Image or SVG formats without having to open each print layout.

hasProcessingProvider=no
changelog=
      1.1.0
        * Layouts can be organised into groups with "/" in their names: "Maps/North/Plan 1" shows as "Plan 1" in the group "North" of the group "Maps"
        * Groups can be created, renamed, removed and exported (subgroups are recreated as subfolders), with "Create Group..." and "Group Selected..." in the context menu
        * Drag and drop layouts and groups to move them to another group; renaming a layout to "Group/Name" moves it too
        * French, Spanish and German translations
        * New basic layout templates from A4 to A0, portrait and landscape: a map using the whole page inside the margins, the project title, a scale bar and a north arrow. Their map opens on the current map canvas view
      1.0.0
        * New "Show Layout Map Extents" map tool: shows the extent of every layout map on the canvas with its layout name, click an extent to open its layout, drag its center handle to move it (undoable), right-click to leave the tool
        * Keyboard shortcuts can be changed in Settings > Keyboard Shortcuts: Ctrl+Alt+L show the panel, Ctrl+Alt+X layout extents tool, and in the layout list Ctrl+N new, Return open, F2 rename, Ctrl+D duplicate, Del remove, Shift+Del remove without confirmation, Ctrl+C copy to clipboard
        * Fixed Ctrl+D in the panel also removing the current layer in QGIS
        * Fixed crashes when exporting layouts as image or with text annotations (#3, #4)
        * Reports are listed in the panel instead of raising errors (#5)
        * Fixed error when a map has an empty extent (#6)
        * Fixed "Save Layout as Template" error
        * The panel is removed properly when the plugin is unloaded or reloaded
        * Filter matches layout names literally (special characters no longer break it), with a placeholder text
        * Removed unused files; only the layout_panel folder is shipped
      0.4
        * Support for QGIS 4 (Qt6)
      0.3
        * Reload the panel automatically at QGIS startup
        * Copy first page of the layout directly to the clipboard
        * Support keyboard shortcuts to delete and rename (F2)
        * Added layout template for A3
        * Export layouts using background tasks
        * Use QGIS settings to manage search patch for layout templates
        * Added map scale in tooltip
        * Added changelog
        * Refactored the code into modules
